# Trial 13: genericity

## Questions

For the same three-line intent, how anchored is each product, how generic, how much leverage does it give, and how long does the person take to review it, in three conditions:

1. an agent alone, with no space;
2. the same agent, in a space with explicit objects;
3. the product of condition 2, after two human iterations.

## Setting

The same three-line intent, the same agent, and a test space with explicit objects.

## Fixed before the trial

- Labeling: an agent that has the space labels each claim; a second agent, without the space, runs the swap test; the person checks a sample.
- The splitting of each product into claims.

## Expected answer

None. We record what each condition gives.

## Measures

From [measures](../../standard/measures.md): anchoring, genericity (swap test), leverage, and the person's review time.

## What could break

Labeling: the swap test, and a label set by an agent, can be unreliable.
