# What you want, as source

What you want, why, and how you'll know, written as small objects that any agent can read, act
on and keep up to date, every change with its reason. A format, a vocabulary and a protocol.

## Why

Intelligence is the engine, compute the fuel, what you want is the source. Without a source, any
agent runs, and writes generic. With one, the same intelligence carries more of what you want.

Every change keeps its reason, so the yield is measured, not claimed. What proves stable can run
without a model at all: intelligence for what's new, the rest compiles (hypothesis).

Standard 0.1 · candidate, untested.

Written by [TheVZion](https://github.com/thevzion/source), which runs on it first.

## What is here

| Path | What it is |
|---|---|
| [`standard/`](standard/) | the standard: the doctrine (how any intelligence behaves) and the structure (objects, links, changes, the trace, truth, access) |
| [`models/`](models/) | the standard library: Purpose, Goals, Work, Loop, Knowledge, Agreements, Capital, and the Organization and Home models that assemble them |
| [`tests/`](tests/) | checks and trials, each a question with its expected answer when there is one |
| [`setup/`](setup/) | the prompt that sets up a space with your agent |
| `git log` | the journal: one change per commit, with `Why:` and `Source:` |

## Use it with your agent

1. Open a folder with any agent that reads and writes files.
2. Paste [`setup/prompt.md`](setup/prompt.md).
3. Say what you want, in your words. The agent writes `space.md` and `objects/`, marks what it
   inferred and commits each change with its reason. You review when you choose.

The folder you get is your source.

Seven questions. One folder. Then it compounds.

To have an agent work on this repository: point it at [`AGENTS.md`](AGENTS.md).

## Contribute

Everything here is a candidate. What didn't fit is the most useful thing you can send.
Open an issue and pick a template:

| Template | When |
|---|---|
| [Propose a change](.github/ISSUE_TEMPLATE/propose-a-change.md) | the standard, a model or a test should say something else |
| [Propose a type or a model](.github/ISSUE_TEMPLATE/propose-a-type-or-model.md) | a question no installed type asks |
| [Report an ambiguous question](.github/ISSUE_TEMPLATE/ambiguous-question.md) | a type's question reads two ways |

Issues are the inbox: a proposal becomes true only by a decision. TheVZion records the decision
in [its source](https://github.com/thevzion/source/tree/main/objects/decisions), then it lands
here as a commit.
