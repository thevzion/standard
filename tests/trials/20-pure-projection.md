# Trial 20: pure projection

## Questions

The same view is asked several times of a pure agent, on the same sources.

1. How anchored is each answer?
2. What does it read outside its sources?
3. When the sources do not say, does it return a question for the person?
4. What varies from one run to the next?

## Setting

A test space and one view. The pure agent receives only the view's question, the sources it links (at a version), the doctrine ([doctrine](../../standard/doctrine.md)), and who the view is for; nothing from the main conversation.

## Fixed before the trial

Not fixed yet. They are written here before the first run, and not changed after.

## Expected answer

None. We record what happens.

## Measures

From [measures](../../standard/measures.md): anchoring; and the reads outside the sources, the questions returned, and the variation between runs.
